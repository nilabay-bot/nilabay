# nilabay
A static coming-soon page for nilabay.com. Open index.html directly or serve this directory with any static web server. No dependencies, build steps, JavaScript, external fonts, or signup services.

- index.html: page copy and accessible artwork descriptions.
- css/style.css: responsive paper-and-paint studio layout.
- images/: optimized 1400px WebP derivatives of the three supplied artworks.
- CNAME: existing custom domain, nilabay.com. Preserve while using the current hosting.

The existing timetrack.html and legacy homepage image are retained to avoid disrupting unrelated URLs. The new homepage does not load them.

## Future storefront
Replace the static page when Shopify is ready. Configure and verify the custom domain in Shopify before changing DNS or retiring current hosting; CNAME alone does not configure Shopify.
